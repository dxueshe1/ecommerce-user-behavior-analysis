这是一个叫做‘电商用户行为分析与增长洞察’的数据分析项目
整个文档分为以下几个部分:
1.data，这里存放一定数量的数据集
2.sql，这里存放项目制作过程中的sql代码
3.python，这里存放项目过程中的python代码
4.tableau这里存放可视化图表和看板
5.report，这个是结果汇报
6.screenshots，存放截图，想看结果图片可以直接看这

2.sql说一下02_user_assort_analysis，因为数据集没有注册时间，所以我们使用用户最早的行为作为注册时间，注册时间在数据集最后一天的前三十天且总使用天数大于一天为老用户，注册时间在数据集最后一天的的前三十天内为新用户，其余为一次性流量
